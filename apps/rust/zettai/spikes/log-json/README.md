## 要求を既定で満たすか

**満たす。両方とも。**

```text
serde: {"ItemAdded":{"item":"読む 本&\"<x>\""}}
tracing: {"timestamp":"...","fields":{"message":"追記した","user":"uberto","appended":2},...}
```

`serde` の derive は**1 つの宣言から両方向を作る**ので、綴りがずれようがない。
`tracing` は構造を持つ記録を出し、**出力先も差し替えられた**（テストで実測）。

**`serde_json` だけでは満たさない。** 書き側と読み側が別のコードのまま。

## それでも入れなかった

**1. `serde` の derive は [ADR-027](../../../../docs/adr/ADR-027-crate-boundary.md) を壊す。**

属性を書く先の `ToDoListEvent` はドメインのクレートにある。**依存 0 を第 3 章から守ってきた**。
鏡の型を HTTP 側に置く手はあるが、**ドメインとの写しを手で書く**ことになり、対であることの利点が
そこで失われる。

**2. `tracing` は +18 クレート・+15.23 秒。** `just check` の余裕は 4 秒弱しかない。

第 11 章で `tera`（+3・18.42 秒）を入れたが、**数字が違う**。
