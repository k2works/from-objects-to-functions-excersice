### HTTP の方式の事前比較（2026-11-27）

第 2 章のゲートの材料として、Unit 1 の完了前に先に比べました。**方式はまだ決めていません。** コードはスクラッチに置き、リポジトリには入れていません。Windows、Node 22.23.4、`effect@4.1.6`、`@effect/platform-node@4.1.6`、TypeScript 7.0.2 で、`tsc` でビルドして実行しました。`@effect/tsgo` と lint は通していません。

要件は、`GET /todo/{user}/{list}` が HTML を返し、それ以外は 404 になることです。3 方式のサーバーを実際に起動し、`node:http` のクライアントから同じ要求を送りました。

| 案 | 構成 |
| :--- | :--- |
| A | stable な部品だけ。ルーティングと `node:http` への接続を自作 |
| B | `effect/http`（unstable）のルーター。`node:http` への接続は自作 |
| C | `effect/http` のルーターと `@effect/platform-node`（unstable）のサーバー |

| 要求への応答 | A | B | C |
| :--- | :--- | :--- | :--- |
| 一覧、日本語と特殊文字を含む名前 | 200 | 200 | 200 |
| HTML の `content-type` | `text/html; charset=utf-8`（自分で指定） | `text/html`（既定では `charset` が無い） | 同左 |
| 無いリスト、無いパス、POST | 404 | 404 | 404 |
| 壊れた URL エンコード | 400（自分で分岐） | 404 | 404 |

| 比較 | A | B | C |
| :--- | :--- | :--- | :--- |
| 空行とコメントを除く行数（共通の部分を除く） | 39（ルート 18 + 接続 21） | 49（ルート 14 + 起動 14 + 接続 21） | 32（ルート 14 + 起動 18） |
| 実行時の package 数 | 1 | 1 | 14（`redis` を含む） |
| unstable の使用 | なし | `effect/http` | `effect/http` と `@effect/platform-node` |

- **A と B の接続の自作は、GET と本文の無い要求だけを扱います。** 後の章でフォームの POST を受けるには、本文の読み取りが要ります。行数はその分を含みません
- HTML の中の値のエスケープは、3 方式とも共通の自作の関数で行いました。`effect/http` がエスケープするかは確かめていません
- 性能、同時の要求、大きな要求、停止中の要求の扱いは確かめていません
