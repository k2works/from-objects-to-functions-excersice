## 仮説の確認

> `R` に依存を載せると、差し替えの漏れが型で分かる。

| `User` と `ListName` を、`name` を持つオブジェクトから、`Brand` を付けた文字列にした | 計画は形を決めていなかった。実行時の値が文字列になり、`Map` のキーを中身で引ける。第 4 章の承認に含む |

| 公開した第 4 章の 3 つの抜粋に、版の注記と検査の除外を足した | 第 5 章の変更で、抜粋の行が実装から消えた。3 つの抜粋の行は、コミット `d27f080` にあることを確かめた |
