## Problem（問題）

| # | Problem | 何が起きたか | 原因 |
| :--- | :--- | :--- | :--- |
| 1 | **`just check` が落ちたままコミットした** | モナド則のテストが clippy で止まっているのに commit した。次のコミットで直した | **`just check` の出力を `grep` で絞って見ていて、`error` の行を読み飛ばした** |
| 2 | **CI の見積もりが外れた** | 「別ジョブなら総時間は増えない」と説明したが、`check` が 26 → 56 秒になった | **依存のコンパイル時間を見積もりに入れていない。** フィーチャで隠せるのはテストの実行だけ |
| 3 | **自前の JSON が DB で落ちた** | `jsonb` の正規化を知らずにパーサを書いた | **往復テストを自分の出力だけで書いた。** 相手（PostgreSQL）が返す形を試していない |
| 4 | 章の frontmatter に余計な行が混ざった | `description` の前に別のキーが入った。公開前に消した | 生成時の書き損じ。**検査は frontmatter の未知のキーを見ない** |

**Problem 1 が一番重い**です。落ちている検査を通ったことにしてコミットしました。**次のコミットで直しましたが、押していれば CI が赤くなっていました。**

Problem 2 と 3 は同じ形です。**「自分が思っている形」だけで確かめ、相手の形を試していません。**
