# スパイク: 失敗の表し方（Unit 4 / ゲート 1・スパイク 1〜3）

## 測った条件（先に決めた）

1. 空のクレートから始める（依存 1 行 = 自分だけ）
2. `cargo add` したあと `cargo clean` してからビルドする
3. 各案とも同じ手順。レジストリのキャッシュは共有（初回 fetch は測らない）

**Unit 3 で「1 回しか測っていない値を比較に使った」失敗をしたので、条件を先に書いた。**

## 結果

| | 自前の `enum` | `thiserror` | `anyhow` |
| :--- | :--- | :--- | :--- |
| 依存クレート（`cargo tree` の行） | **1**（自分だけ） | **11** | **2** |
| 依存のビルド（clean から） | **0 秒** | **12.29 秒** | **2.15 秒** |
| 与えるもの | 何も | `Display` の導出・`#[from]` | 型を 1 つに潰す・文脈の積み上げ |
| 失敗を `match` で分けられるか | **できる** | **できる** | **できない**（型が消える） |

## `?` は経路をまたいで使えるか

**使える。** `From` を 1 つ書けば、`?` が自動で変換する（`src/lib.rs`）。

```rust
impl From<DomainError> for HttpError {
    fn from(e: DomainError) -> Self {
        HttpError::Domain(e)
    }
}
```

`thiserror` はこの `From` を `#[from]` で書かせてくれる。**それが与えるものの中身。**
