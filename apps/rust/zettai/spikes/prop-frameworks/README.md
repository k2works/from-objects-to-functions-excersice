## 検出率は測れるか

**測れる。ただしループは自分で書くことになる。**

どちらも「最初の反例で止まる」設計で、[ADR-017](../../../../docs/adr/ADR-017-own-property-testing.md) が要求する
「200 回中何回検出したか」とは向きが逆。数えるには `TestRunner` を `cases: 1` で
200 回まわす（`src/lib.rs`）。

```text
検出 19 / 200
```

法則を `a == 7` のときだけ壊し、`a` を `0..10` から引いた。**期待値 20、標準偏差 4.24**。
19 は期待どおり。

**このとき枠組みが担っているのは生成器だけで、縮小も再現用の種も使っていない。**
