## ゲートの説明の訂正

ゲート ② で、案 A の代償を「後始末は型に現れない」と説明しました。**一部が誤りでした。** 実装の後に確かめると、`Effect.scoped` を忘れると型検査が失敗します。型で止まらないのは、閉じないスコープを渡した場合です。経路の型 `Route` が後始末の約束を表さないことは、説明どおりです。選択を変えるほどの違いではないと考えますが、判断は人に委ねます。ADR-057、Bolt 計画、第 3 章は直しました。
