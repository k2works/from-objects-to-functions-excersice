## Problem（問題）

| # | Problem | 何が起きたか | 原因 |
| :--- | :--- | :--- | :--- |
| 1 | **測る道具そのものにバグを入れていた** | 検出率のしきい値を期待値から 1.58 標準偏差の位置に置き、正しい実装でも約 6% で落ちるテストになっていた | **しきい値を決めるときに分布を計算しなかった。** 「100 なら十分低い」と目分量で置いた |
| 2 | **段階をコピーして取り込みパスを直し忘れた** | `src/step4` → `step5` をコピーしたとき、テスト 21 ファイルが step4 を取り込んだまま。**step5 のテストが step4 を検査していた** | コピーで段階を作る手順が文書化されていない。[ADR-015](../adr/ADR-015-step-directories.md) は「切る」としか書いていない |
| 3 | **記録先が全テスト共有で、並列実行時に競合した** | 件数を数えるテストが、他のテストの書き込みと混ざった | 記録を入れた時点で「並列に走る」ことを考えていなかった |
| 4 | **記事の全文検証のゲートは今回も止まらなかった** | 3 箇所中 2 箇所（7-1.9・7-2.5）は通り過ぎた | **判断を求めていないゲートは止まらない。** Keep 1 の裏返し |
| 5 | **ADR-022 への追記を「不要」と判断したが、計画には理由を書いていない** | 計画は「テンプレートの穴を見直す」としていたが、画面が増えないので判断のみで終えた | 計画の段階で「どうなったら不要か」を書いていなかった |

Problem 1 が最も重い問題です。**性質テストで実装を検査してきたのに、検査する側の統計を確かめていませんでした。**

Problem 2 は影響が大きい割に見つけにくい種類でした。`grep -rl step4 test/step5` で一括検出できたので、**手順にすれば防げます。**

## Try（次に試すこと）

連載は完結したので、Try は **3 言語目**（または本連載の改訂）への引き継ぎです。

| # | Try | 期待効果 | 契機 |
| :--- | :--- | :--- | :--- |
| 1 | **しきい値を置くときは分布を計算する**（Problem 1） | 検出率のような確率的な指標にしきい値を置くなら、期待値と標準偏差を出し、**5 標準偏差以上離す**。目分量で置かない | 3 言語目の最初の性質テスト |
| 2 | **段階を切る手順を ADR-015 に書く**（Problem 2） | コピー → 取り込みパスの一括置換 → `grep` で残りを確認、を手順にする。**確認のコマンドまで書く** | 3 言語目の段階 2 つめ |
| 3 | **ゲートには必ず選択肢と数字を添える**（Keep 1・Problem 4） | 「確認してください」と書くゲートは置かない。**判断を求めないなら、それはゲートではなくチェック項目**として DoD に書く | 3 言語目の計画 |
| 4 | **共有する書き込み先は、最初からテストごとに分ける**（Problem 3） | ファイルに書くものを足すときは、その時点で「並列に走ったらどうなるか」を確かめる | 3 言語目で永続化を入れるとき |
| 5 | **計画の「見直す」には、不要と判断する条件を添える**（Problem 5） | 「画面が増えなければ見直さない」のように、やらない条件を先に書く | 3 言語目の計画 |

## 連載全体のふりかえり

7 Unit を通した数字です。

| 指標 | 実績 |
| :--- | :--- |

### 効いた仕組み 3 つ

1. **既知の制約の一覧**（Unit 6 から）。作って読むだけで、第 10 章の設計の間違いが 0 になった。**3 回踏んでから作ったのが遅すぎた**
2. **法則を壊して検出率を測る**（Unit 3 から）。「法則が通った」ではなく「壊したら落ちる」を確かめた。7 構造すべてで、捕まえない壊し方が見つかった
3. **同じシナリオを複数経路で走らせる**（Unit 2 から）。Unit 6 で経路固有の実装欠陥（`/rename` 以外への POST）を捕まえた

### 効かなかった仕組み 2 つ

1. **承認ゲート**。41 箇所中 1 回。**書いても止まらないものを計画に並べ続けた**のが 6 Unit 分の誤りだった
2. **「人が検証に使った時間」という指標**。6 Unit 連続で空欄。**測れない指標は、指標が無いより悪い**（空欄でも「指標がある」つもりでいられる）
