## Problem（問題）

| # | Problem | 何が起きたか | 原因 |
| :--- | :--- | :--- | :--- |
| 1 | **`git checkout` で第 6 章の実装を消した** | lint の検証のために書き換えたファイルを戻すとき、**未コミットの実装ごと消した**。書き直した | **Unit 3 Try 3 は「`git stash` を使わない」としか書いていなかった。** 同じ形の操作（取り消し）に広げていない |
| 2 | 単体の Red を立てずに書いた箇所が残った | `state_of_list` と `execute_in` の分離は、テストより先に実装した | Unit 3 Try 4 を全ステップには適用できていない |
| 3 | **`execute_in` で空文字を詰めた** | 失敗が `user` と `list_name` を持つようになったとき、**とりあえず `User::new("")` で埋めた**。すぐ直した | 型を通すことを優先し、**意味を後回しにした** |
| 4 | 段階を切った直後の初回が上限を超えた | 36.25 秒（上限 20 秒） | **段階が増えるほど初回が伸びるのは構造上避けられない。** 定常は上限内 |

**Problem 1 が一番重い**です。Unit 3 で `git stash drop` で成果を消し、Try を書きました。**その Try が狭すぎて、同じ形の事故を防げませんでした。**

「`git stash` を使わない」ではなく「**取り消し操作の前に、作業ツリーが commit 済みかを確かめる**」が正しい形でした。
