# ADR-036 テンプレートに tera を入れる

日付: 2026-09-29

## ステータス

2026-09-29 提案されました

## コンテキスト

第 11 章で画面にエラーを並べます。第 10 章まで HTML は `format!` の直書きで、**値を無害化していませんでした**。

2 対象はここでテンプレート機構を**自作**しました。

| 対象 | 決定 | 理由 |
| :--- | :--- | :--- |
| Kotlin | 自作（[ADR-010](ADR-010-own-template.md)） | **既製品は未適用のタグを空文字か例外にするだけで、`Outcome` に乗らない** |
| なでしこ3 | 自作（[ADR-022](ADR-022-template-with-unfilled-check.md)） | 寄せる先が無い |

**要求は 1 つです。**

> タグを書いたのにデータを渡し忘れたら、**失敗として扱う。**

### 測った条件（先に決めた）

1. 空のクレートから始める
2. `cargo add` したあと `cargo clean` してからビルドする
3. 各案とも同じ手順

### 結果

| | 自前 | `askama` | **`tera`** | `minijinja` |
| :--- | :--- | :--- | :--- | :--- |
| 依存クレート | +0 | **+18** | **+3** | +4 |
| 依存のビルド | 0 秒 | **28.56 秒** | **18.42 秒** | 23.53 秒 |
| **未適用のタグ** | 自分で書く | **コンパイル時に止まる** | **既定で `Err`** | 既定は空文字。`Strict` で `Err` |

**Kotlin 版の理由は成り立ちませんでした。**

```text
tera: Err(Error { kind: RenderingError(... message: "Variable `forgotten` is not defined.
      Available variables: name" ...) })
```

`tera` は**既定で `Result` を返し、足りない変数の名前まで挙げます**。`askama` はさらに強く、コンパイル時に止まります。

```text
error[E0609]: no field `forgotten` on type `&ListPage`
```

## 決定

**`tera` を入れます。テンプレート機構を自作しません。**

1. テンプレートは文字列として持ち、`add_raw_templates` で登録する
2. **名前を `.html` にする。** 自動エスケープは拡張子で決まる（下記）
3. `tera::Error` を**ドメインに出さない**。`ZettaiError::StoreUnavailable` に包む（[ADR-027](ADR-027-crate-boundary.md)）
4. 描画は `Result<String, ZettaiError>` を返す

### なぜ自作しないのか

**要求を既定で満たす既製品があるのに自作すると、理由のない自作になります。** 連載は「既製品を先に調べる」を全 Bolt 共通のゲート項目に置いています（[開発戦略](../development/development_strategy.md)）。第 3 章の `cucumber`、第 5 章の `proptest`、第 7 章の `thiserror`、第 9 章の `serde_json` は**数字が合わなかったから**入れませんでした。**`tera` は数字が合いました。**

**3 対象で初めて、既製品に寄せる判断になりました。**

### 検討した代替案

| 案 | 採らなかった理由 |
| :--- | :--- |
| 自作（[ADR-010](ADR-010-own-template.md)・[ADR-022](ADR-022-template-with-unfilled-check.md) の踏襲） | **理由が無い。** 要求を既定で満たす既製品がある |
| `askama` | 要求より強い（コンパイル時）が、**依存 +18・ビルド +28.56 秒**。Unit 5 の学び（依存を足すと `check` も遅くなる）がそのまま効く。加えて**テンプレートが型に縛られ、エラーの本数が実行時に決まるこの章と相性が悪い** |
| `minijinja` | `tera` と同等だが、**既定が安全でない**（空文字になる）。`Strict` の設定を忘れると気づけない |

## 影響

- **値が無害化されます。** 第 10 章までの `format!` 直書きには無い性質でした
- 依存が 1 つ増えました。**`check` の秒数への影響を記録します**（Unit 5 の持ち込み 6）
- `tera::Error` はドメインに出ません。境界で包みます

### つまずき: 既定では自動エスケープが効かなかった

**「既製品を入れたから安全」ではありませんでした。**

`tera` の自動エスケープは**テンプレート名の拡張子**で決まります。`"list"` という名前で登録すると効きません。

```text
生のタグが残っている: <html><body><h1>book</h1><ul>
<li><script>alert(1)</script></li>
```

`"list.html"` に変えて通りました。**既定が安全かどうかは、入れてから確かめる必要があります。**

### この決定が解かないこと

| 解かないこと | どうするか |
| :--- | :--- |
| **テンプレートをファイルに出すか** | いまは文字列定数です。**増えたらファイルに出します**。`tera` はどちらもできます |
| エンジンを毎回作っていること | `engine()` が呼ばれるたびに `Tera` を組み立てています。**測って遅ければキャッシュします**。いまの規模では測れる差がありません |
| Jinja2 の構文の説明 | 記事では**使う分だけ**触れます。テンプレートの書き方は主題ではありません |
| 2 対象との比較 | **自作と既製品では中身が違います。** 第 13 章で「同じ要求に 3 通りの答えが出た」として並べます |

## コンプライアンス

- ドメインの `Cargo.toml` に `tera` が現れないこと
- テンプレート名が `.html` で終わること（自動エスケープのため）
- **「渡し忘れたら失敗になる」テストがあること**
- **「危ない値が無害化される」テストがあること**
