# 第 13 章 関数型アーキテクチャの設計

12 章かけて Zettai を作りました。**この章ではコードをほとんど書きません。**

積み上げたものが何だったのかを整理します。そして**3 言語で同じ題材を書いた結果**を並べます。

## シンプルさを追い求めて

この連載が「シンプル」と呼んだのは、**判断が 1 か所にあること**でした。

| 何を | どこに集めたか | 章 |
| :--- | :--- | :--- |
| 「足してよいか」 | `execute_in`（遷移表） | 6 |
| 「どこまでが 1 単位か」 | `handle_in_transaction` | 10 |
| 「名前が正しいか」 | `valid_new_name` | 11 |
| 「どこに保存するか」 | 配線の 1 行 | 4 |

**呼ぶ側には判断がありません。** HTTP のハンドラは理由を状態コードに写すだけ、保管は言われたものを書くだけです。

## システム全体の設計

13 章を通して守った性質が 1 つあります。**ドメインのクレートは依存を 1 つも持ちません。**

```text
zettai-step5-domain/Cargo.toml
[dependencies]
（空）
```

第 3 章で決め（[ADR-027](../../../adr/ADR-027-crate-boundary.md)）、**最終章まで崩していません**。

この性質のおかげで、**境界検査を 1 行も書いていません**。2 対象は書きました。

| 対象 | 境界を守るために書いたもの |
| :--- | :--- |
| Kotlin | `DomainBoundaryTest`（import を検査） |
| なでしこ3 | `boundary_test.nako3`（7 ファイル × 5 項目 = 35 件） |
| **Rust** | **無し** |

そして第 12 章で、この性質が**判断の根拠**になりました。`serde` の derive は要求を満たしていましたが、**属性をドメインの型に書く必要がある**ので入れていません（[ADR-037](../../../adr/ADR-037-own-logging.md)）。

**12 章通しで守ったものは、最終章で判断の重みになります。**

## コードへの翻訳

### 数えたもの

| 項目 | 数 |
| :--- | :--- |
| 公開した章 | **13** |
| ADR | **14 件**（024〜037） |
| 既知の制約 | **13 件** |
| 設計に効いたもの（所有権・借用・ライフタイム） | **7 件** |
| clippy に押されたもの | **5 件** |
| 性質テストで確かめた代数構造 | **5 つ** |
| テスト | **287 件** |
| workspace メンバー | **10**（5 段階 × 2 クレート） |
| 本体の依存クレート（直接） | **3**（`tiny_http` / `postgres` / `tera`） |

**ADR が 14 件は、3 対象で最多**です。Kotlin 版が 12 件、なでしこ3 版が 11 件でした。

**書いたコードは最も少ない言語で、決めたことは最も多い**という結果になりました。

### 制約が設計を押した 7 回

この連載の Intent はこれでした。

> なでしこ3 版で 5 回起きた「制約が設計を押す」現象が、**型の側の制約（所有権・借用・ライフタイム）でも起きるか**

**起きました。7 回です。**

| # | 押された箇所 | 押された先 | 章 |
| :--- | :--- | :--- | :--- |
| 1 | 一時値が借用中に破棄された（E0716） | 一度変数に受ける。**2 行に分かれて読みやすくなった** | 2 |
| 2 | 同じクレートだと相互参照できてしまう | **クレートを分けた。** 境界検査が要らなくなった | 3 |
| 3 | 合成を型で表すと畳み込めない（E0308） | **合成を値で持つ。** モノイドの形がそのまま出た | 4・5 |
| 4 | クロージャに借りた値を閉じ込められない | **借りずに所有する。** イベントの形に合う | 5 |
| 5 | ハブの戻り値に `impl Fn` を 2 つ書けない | **`Box<dyn Fn>` にして名前を付けた。** 配線が 1 か所に寄った | 7 |
| 6 | トランザクションを値として返せない（E0515・E0505） | **区間として貸す。** `commit` の呼び忘れが起こりえなくなった | 10 |
| 7 | 中身が空の文脈を作れない（E0478） | **文脈に動詞を持たせた。** Kotlin 版の実行時検査が要らなくなった | 10 |

**7 回とも、押された先のほうが読みやすい形でした。**

なでしこ3 版は**型が無いこと**に 5 回押され、5 回とも関数型として素直な方向へ動いています。**制約の出どころが型でも型の不在でも、押された先は同じでした。**

### 既製品を 7 回判断して、入れたのは 1 回

**2 対象にほとんど無い判断です。**

| 章 | 既製品 | 要求を満たすか | 判断 | 決め手 |
| :--- | :--- | :--- | :--- | :--- |
| 3 | `cucumber` | 満たす | 入れず | 依存 +121・ビルド +92 秒 |
| 5 | `proptest` | 満たす | 入れず | 依存 +38・26.77 秒 |
| 7 | `thiserror` | 満たす | 入れず | 中身は `impl From` 1 つ |
| 9 | `serde_json` | **満たさない** | 入れず | 対にならない |
| **11** | **`tera`** | **満たす** | **入れた** | **自作する理由が消えた** |
| 12 | `tracing` | 満たす | 入れず | 依存 +18。`check` の余裕が 4 秒弱 |
| 12 | `serde` derive | 満たす | 入れず | **依存 0 が壊れる** |

**入れなかった 6 回の理由は同じではありません。** 数字が合わないが 4 回、要求を満たさないが 1 回、**別の性質が壊れる**が 1 回でした。

そして**第 11 章だけ結論が変わりました**。Kotlin 版が自作した理由（既製品は未適用のタグを失敗にできない）が、Rust では成り立たなかったからです。

**「毎回調べる」を手順にしていなければ、11 回目も自作していました。**

### 代数構造は言語に関係なく現れた

| 構造 | 章 | Kotlin | なでしこ3 | Rust |
| :--- | :--- | :--- | :--- | :--- |
| モノイド | 5 | 自作 | 自作 | 自作 |
| ファンクタ | 7・8 | 自作 | 自作 | **言語にある** |
| モナド | 9 | 自作 | 自作 | **言語にある** |
| アプリカティブ | 11 | 自作 | 自作 | 自作 |
| プロファンクタ | 12 | 自作 | 自作 | 自作 |

**言語が与えたのは 2 つだけ**でした。

そして**確かめ方は 3 対象で同じ**です。法則を壊して検出率を測ります。

| 構造 | 壊し方 | 検出 | 期待値（σ） |
| :--- | :--- | :--- | :--- |
| モノイド | `item7` のときだけ足さない | 12 / 200 | 15（3.72） |
| ファンクタ（`Result`） | 項目 2 件のとき飛ばす | 50 / 200 | 50（6.12） |
| ファンクタ（射影） | 件数 2 のとき飛ばす | 61 / 200 | 50（6.12） |
| モナド | 項目 1 件のとき飛ばす | 47 / 200 | 50（6.12） |
| アプリカティブ | 片方の理由を捨てる | 56 / 200 | 50（6.12） |
| プロファンクタ | **片方だけ直す** | 188 / 200 | 180（4.24） |

**しきい値は毎回 3〜4σ 下に置きました。** なでしこ3 版は 1.58σ に置いて、**CI が確率 5.7% で落ちています**。

射影のファンクタで実測が **1.8σ** ずれたときは、生成器を疑って種を 20 通り変えて数え直しました（平均 50.1）。**「ずれた」と「間違っている」は別物です。**

## 最後の考察

### 言語が与えるほど、設計は楽になるのか

**答えは「楽にはならない。決めることが変わる」でした。**

| 対象 | 何を決めたか | ADR |
| :--- | :--- | :--- |
| Kotlin | **何を作るか** | 12 件 |
| なでしこ3 | **足りないものをどう埋めるか** | 11 件 |
| Rust | **与えられたものを使うか、作るか** | **14 件** |

なでしこ3 は**足りないから決める**ことになりました。Rust は**多いから決める**ことになりました。

**書くコードが減っても、判断は減りません。** むしろ増えました。

### 型は何を守り、何を守らなかったか

**守った範囲は、思っていたより狭いところがあります。**

| 何を | 守ったか |
| :--- | :--- |
| 境界（ドメインが HTTP を呼ばない） | **守った**（クレート） |
| 遷移表の枝が揃っているか | **守った**（E0004） |
| **遷移表の行き先が正しいか** | **守らない** |
| **ワイルドカードで網羅を無効にすること** | **守らない**（組で受けると lint も効かない） |
| 失敗を捨てること | **守った**（`Result` は `#[must_use]`） |
| CQRS でコマンド側とクエリ側を混ぜること | **守った**（型が違う） |
| **クエリ側から状態を変えること** | **守らない** |

なでしこ3 版は「コンパイラが無いから数える」と書きました。**Rust は「コンパイラがあっても数える。守る範囲が違うから」**です。

### 承認ゲートの実践結果

この連載は AI-DLC で進めました。**人が同期的に停止して判断する箇所**を計画に置いています。

| 対象 | 計画した箇所 | 停止した回数 |
| :--- | :--- | :--- |
| Kotlin + なでしこ3 | 41 | **1** |
| **Rust** | **15** | **15（100%）** |

**Rust 版で変えたのは、ゲートの書き方を規約にしたことだけ**です。

1. **選択肢と数字を添えられないものは、ゲートにしない**
2. ゲートには「選択肢」「それぞれの結果（数字）」「調べた事実」を添える

2 対象の 41 箇所のうち止まった 1 回にも、この 3 つが揃っていました。**箇所を増やしても止まらず、書き方を変えたら全部止まりました。**

そして**ゲートの数をエントロピー評価で増減させ、4 回とも当たりました**（Unit 4 で減らし、5 で戻し、6 で増やし、7 で減らした）。

### 扱わなかったこと

**5 件あります。**

| # | 扱わなかったこと | なぜ |
| :--- | :--- | :--- |
| 1 | **スナップショットとリードモデルの永続化** | 全イベントを読んで畳み込んでいます。件数が増えたときの手を決めていません |
| 2 | **接続プールと並行処理** | `Mutex<Client>` 1 本です。1 リクエストずつ扱う前提です |
| 3 | **トランザクションの分離レベル** | 既定のままです。繰り返し読みの一貫性を確かめていません |
| 4 | **単位を跨ぐ処理** | 1 コマンドが 1 単位です。複数をまとめる話は範囲外です |
| 5 | **認証と認可** | 利用者名をパスから取るだけです |

**1 と 2 は Kotlin 版とも共通**です。3 と 4 は Rust 版で第 10 章を書いたときに明示しました。

### `async` を採らなかった判断について

第 1 章で「`async` を採らない」と決めました（[ADR-024](../../../adr/ADR-024-no-async.md)）。**後戻りの効かない判断**で、第 9 章で試されました。

**持ちこたえました。** ただし中身は「**困らなかった**」であって、「同期のほうが良かった」ではありません。1 プロセスで 1 リクエストずつ扱う規模だから困らなかっただけです。

**判断が正しかったかは、この連載の規模では分かりません。** 分かったのは「**この規模なら同期で 13 章書ける**」ことだけです。

## 連載を終えて

- **ドメインのクレートは 13 章通して依存 0 でした。** 境界検査を 1 行も書いていません
- **制約が設計を押したのは 7 回**で、7 回とも押された先が読みやすい形でした。**型の存在でも、型の不在でも同じ**です
- **既製品を 7 回判断して、入れたのは 1 回**です。入れなかった 6 回の理由は同じではありません
- **代数構造は 5 つとも現れました。** 言語が与えたのは 2 つだけです
- **型が守る範囲は、思っていたより狭いところがあります。** 遷移表の行き先は守りません
- **書くコードが減っても、判断は減りませんでした。** ADR は 3 対象で最多の 14 件です
- **承認ゲートは 15 / 15 で止まりました。** 変えたのは書き方の規約だけです
- **扱わなかったことが 5 件あります**

「言語が与えるほど設計は楽になるのか」への答えは、**「楽にはならない。決めることが変わる」**でした。
